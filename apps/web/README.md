# 3ain (عين)

A facial recognition civic identity app built for Libya. Captures a face photo via device camera, analyzes it through a DeepFace-powered backend (emotion, age, gender, race), and matches against a citizen database for identity verification. Results displayed in Arabic with full RTL support.

Features:
- Camera capture - real-time face photo from device camera
- DeepFace analysis - emotion, age, gender, race classification
- Identity matching - matches against citizen records
- Arabic UI - fully translated interface with RTL layout

Tech Stack: Next.js 14 + TypeScript, Tailwind CSS + shadcn/ui, DeepFace backend (Python/FastAPI)

Deployed on Vercel: https://3ain-sigma.vercel.app
