# 3ain_vehicle (عربة)

A car license plate recognition app built for Libya. Captures vehicle license plates via device camera and performs OCR-based recognition to identify and process plate numbers.

Features:
- Real-time license plate capture from device camera
- OCR-based plate number recognition
- Arabic language interface

Tech Stack: Next.js 14 + TypeScript, Tailwind CSS + shadcn/ui

Deployed on Vercel: https://3ain-vehicle.vercel.app
